## 🐛 Troubleshooting

### Animations not smooth?
```typescript
// Make sure native driver is enabled
useNativeDriver: true
```

### Colors not updating with theme?
```typescript
// Use colors from useTheme()
const { colors } = useTheme();
```

### Touch targets too small?
```typescript
// Minimum 44x44
minWidth: 44, minHeight: 44
```

### Layout shift on scroll?
```typescript
// Use absolute positioning for header
position: 'absolute'
```
